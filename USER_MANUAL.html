2 One-Time Setup Guide (Step-by-Step for Beginners)

Before running the application for the very first time, you need 3 free helper tools installed on your computer. You only need to do this once!

Step A: Install Node.js (Required to run the Web App)
  1. Go to https://nodejs.org/ in your browser.
  2. Download the "LTS (Recommended For Most Users)" installer.
  3. Double-click the downloaded file and click Next -> Next -> Finish (keep all default settings).
Step B: Install Python (Required for the AI Speech Engine)
  1. Go to https://www.python.org/downloads/.
  2. Click the big yellow "Download Python" button.
  3. CRITICAL STEP: When opening the installer, check the box that says "Add python.exe to PATH" at the bottom before clicking Install Now!
Step C: Install FFmpeg (Required for Audio Extraction)
  • On Windows: Open Command Prompt and type: winget install FFmpeg and press Enter.
  • On Mac: Open Terminal and type: brew install ffmpeg and press Enter.
  • On Ubuntu/Linux: Open Terminal and type: sudo apt update && sudo apt install -y ffmpeg.
Step D: Initialize the Project (First Time Only)

Open your Terminal or Command Prompt in the project folder and copy-paste these 2 simple commands line-by-line:

# 1. Install all necessary packages (Takes 1-2 minutes)
npm install

# 2. Prepare the local database
npm run db:setup

5 How to Import Subtitles into Video Editors

Follow these quick guides to bring your downloaded .srt file into your preferred video editing software:

🎬 Adobe Premiere Pro
  1. Open your Premiere project.
  2. Go to File -> Import and select your downloaded .srt file.
  3. Drag the imported SRT file from the Project panel directly onto your timeline as a Caption track.
  4. Style your subtitle font, color, and size in the Essential Graphics / Captions panel!
🎨 DaVinci Resolve
  1. Open DaVinci Resolve and go to the Edit Page.
  2. Right-click in the Media Pool and select Import Media... -> Pick your .srt file.
  3. Drag the subtitle onto your timeline. It will automatically create a dedicated Subtitle Track.
  4. Customize font and outline in the Inspector -> Caption tab.
📱 CapCut (Desktop / Mobile)
  1. Open your video in CapCut.
  2. Click Text on the top menu -> Click Local Captions / Import SRT.
  3. Select your downloaded .srt file.
  4. CapCut will automatically align the subtitles with your video timeline!
▶️ YouTube Studio
  1. Go to YouTube Studio and select your video.
  2. Click Subtitles on the left menu.
  3. Click Add / Edit -> Select Upload file -> Choose With timing.
  4. Select your .srt file and click Publish!

6 Troubleshooting & FAQs (For Non-Techies)

❓ Question 1: I double-clicked start_app.bat but the browser says "This site can't be reached"?
Answer: Wait 5 to 10 seconds for the black server window to finish initializing. Do NOT close the black command window — it must stay open while you use the application!
❓ Question 2: It says "FFmpeg not found"?
Answer: FFmpeg is required to extract audio from video files. Open Command Prompt on Windows and type winget install FFmpeg, then restart your computer.
❓ Question 3: Some Banglish words are spelled wrong?
Answer: Simply type those tricky Banglish words into the Custom Vocabulary Prompt box before clicking Generate! The AI will automatically adopt your exact spellings.
